Especificaciones

Diseñada para la utilidad real y la autonomía

Cada componente resuelve una necesidad cotidiana de captura y seguimiento sin añadir complejidad superflua.

AlarmManager del Sistema

Recordatorios con Notificaciones Exactas

La aplicación programa alertas a nivel de sistema operativo utilizando AlarmManager.setExactAndAllowWhileIdle. Esto garantiza que las notificaciones se emitan con precisión en la fecha y hora indicadas, incluso si el dispositivo entra en modo de ahorro de batería o suspensión profunda (Doze Mode).

Compatibilidad Android 13+ (POST_NOTIFICATIONS)
Comportamiento al borrar nota Cancelación automática del PendingIntent
Organización

Validación de Carpetas

Control formal de entradas: límite de 25 caracteres por carpeta, detección en tiempo real de nombres duplicados y prevención de registros vacíos.

Integridad Borrado en cascada
Almacenamiento Interno

Persistencia de Fotografías

Las imágenes seleccionadas desde la galería se copian físicamente a la carpeta interna privada de la aplicación (filesDir/note_images/). Esto evita la pérdida de imágenes si el archivo original es movido o eliminado en la galería externa.

Formato JPEG comprimido (85% calidad)
Acceso Aislado al sandbox de la app
Privacidad Estricta

Base de Datos Room SQLite

No requiere registro, conexión a servidores remotos ni sincronización en nubes externas. La base de datos relacional reside únicamente en el disco de tu dispositivo, garantizando tiempos de respuesta instantáneos y confidencialidad completa.

Motor SQLite con Room DB v8
Dependencia de red Cero (100% desconectado)
Guía de Instalación

Cómo instalar el archivo APK en tu dispositivo

Al tratarse de una compilación directa fuera de Google Play, solo debes autorizar la instalación en tu teléfono.

Paso 01

Descarga el archivo

Toca el botón de descarga desde el navegador de tu teléfono Android para obtener el archivo notes-app.apk directamente.

Paso 02

Habilita orígenes desconocidos

Si el instalador del sistema te notifica un bloqueo de seguridad, presiona «Ajustes» y activa «Permitir desde esta fuente» para continuar.

Paso 03

Abre y utiliza

Finalizada la instalación, pulsa «Abrir». La base de datos local SQLite se inicializará automáticamente y podrás comenzar a tomar notas.
